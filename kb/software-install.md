# Installing software

Most software is available in the Software Center and installs without admin rights.

## Software not in the Software Center
Request it through the service desk with the product name, the business reason and the number of licences. IT security checks new software within 3 working days. Free tools are also checked, because licences often forbid commercial use.

## Admin rights
Local admin rights are only given to developers for a limited time of 30 days, after approval by the team lead.

## Updates
Windows and Office updates install automatically on Wednesday nights. Leave your laptop on and connected to power on Wednesday evening once a month.
