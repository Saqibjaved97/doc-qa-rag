# Files, OneDrive and backups

Store personal work files in OneDrive and team files in the team's SharePoint site. Do not keep important files only on the laptop's desktop.

## Restoring deleted files
Deleted files stay in the OneDrive recycle bin for 93 days. You can restore earlier versions of a document from the version history.

## Old network drives
The old S: drive is read-only since March 2026 and will be switched off at the end of the year. Move files you still need to SharePoint.

## Backups
SharePoint and OneDrive are backed up every night and kept for one year. If a whole folder was deleted more than 93 days ago, the service desk can restore it from backup.
