# Email and shared mailboxes

Every team can have a shared mailbox, for example logistics-support@nordwind.example.

## Getting access
The owner of a shared mailbox, usually the team lead, can approve access. Request access in the Self-Service portal under "Mailbox access". It appears in Outlook within an hour.

## Mailbox full
Personal mailboxes have 50 GB of storage. When you reach 45 GB, archive old emails with the Archive button or move attachments to OneDrive.

## Out-of-office
Set automatic replies in Outlook under File, Automatic Replies. For shared mailboxes, ask the mailbox owner to set them.
